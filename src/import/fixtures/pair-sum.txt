1. Pair With Target Sum
Easy
Given a list of integers nums and an integer target, return the indices of the two different entries whose values add up to target.

Exactly one valid pair exists. Return the smaller index first.

 

Example 1:

Input: nums = [3,8,1,6], target = 9
Output: [1,2]
Explanation: nums[1] + nums[2] = 8 + 1 = 9.
Example 2:

Input: nums = [5,5], target = 10
Output: [0,1]
 

Constraints:

2 <= nums.length <= 10^4
-10^9 <= nums[i] <= 10^9
