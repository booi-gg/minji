# Reverse the Words

Given a sentence `s`, return the words in reverse order, separated by single spaces. Words are separated by one or more spaces; punctuation stays attached to its word.

```typescript
function reverseWords(s: string): string {
}
```

**Example 1:**

```
Input: s = "the sky, blue"
Output: "blue sky, the"
```

**Example 2:**

```
Input: s = "  hello   world "
Output: "world hello"
```

**Constraints:**

- `1 <= s.length <= 10^4`
